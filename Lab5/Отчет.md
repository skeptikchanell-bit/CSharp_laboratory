## Задача 1

### Текст задачи

Разработать консольное приложение с дружественным
интерфейсом. Реализовать чтение базы данных
из Excel-файла, состоящей из трёх таблиц:
«Клиенты», «Бронирование», «Номера».

### Алгоритм решения

1. Подключить библиотеку `ExcelDataReader` для
   чтения формата `.xls`.
2. Зарегистрировать кодировку `CodePagesEncodingProvider`
   для корректного чтения кириллицы.
3. Прочитать 3 листа из файла в `DataSet`.
4. В цикле пройтись по строкам каждого листа
   и создать объекты `Client`, `Booking` и `Room`.
5. При чтении цен из листа «Номера» (столбец D)
   убрать символы «р.», «руб.», пробелы и заменить
   запятую на точку для успешного парсинга в `decimal`.
6. Пропускать пустые или обрезанные строки
   (в листе «Бронирование» последняя строка
   не содержит даты выезда).
7. Обернуть процесс чтения в `try-catch`
   для перехвата ошибок формата файла.

## Задача 5

### Текст задачи

Реализовать 4 запроса с использованием LINQ:
1. 1 запрос к одной таблице (возвращает перечень).
2. 1 запрос к двум таблицам (возвращает значение).
3. 2 запроса к трём таблицам (один — перечень,
   второй — значение).
4. В качестве примера использовать задание:
   «Определить общую стоимость проживания за сутки
   в номерах категории 5, забронированных клиентами
   из г. Уфа с 1 по 16 июня включительно».
   Ответ должен быть 37199.

### Алгоритм решения

1. **Запрос 1 (1 таблица, перечень).**
   `Clients.Where(c => c.Residence.Contains("Уфа"))`.
   Возвращает список клиентов из Уфы.
2. **Запрос 2 (2 таблицы, значение).**
   `from b in Bookings join c in Clients...`
   Вычисляет среднюю длительность проживания
   через `Average()`.
3. **Запрос 3 (3 таблицы, перечень).**
   Связывает `Clients`, `Bookings`, `Rooms`.
   Фильтрует по городу Уфа.
   Возвращает список строк: `"ФИО -> Номер (Категория)"`.
4. **Запрос 4 (3 таблицы, значение).**
   Связывает `Clients`, `Bookings`, `Rooms`.
   Фильтрует по городу Уфа, категории 5
   и датам бронирования (с 01.06.2019 по 16.06.2019).
   Суммирует цены через `Sum()`.

## 1. Цель работы

Изучить делегаты, события, анонимные методы и Language Integrated Query (LINQ) в C#. Приобрести навыки обработки данных из Excel-файла с помощью LINQ-запросов.

## 2. Задание

Дан файл `LR5-var9.xls` с двумя листами:
- **«Клиенты»** — код клиента, ФИО, место жительства (700 записей).
- **«Бронирование»** — код брони, код клиента, код номера, даты брони/заезда/выезда (400 записей).

Требуется:
1. Прочитать данные из Excel.
2. Связать таблицы по коду клиента.
3. Построить отчёт: для каждого клиента — количество броней и суммарные дни проживания, отсортировать по убыванию дней.
4. Вывести клиентов без броней.
5. Построить топ-10 городов по числу клиентов.

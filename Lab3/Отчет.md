# Задание 2

## Задача 9

### Текст задачи

**9. Работа с двумерными массивами.**

Задан двумерный массив. Найдите сумму элементов первого столбца без одного последнего элемента, сумму элементов второго столбца без двух последних, сумму третьего столбца без трех последних и т.д. Последний столбец не обрабатывается. Среди найденных сумм найдите максимальную.

### Алгоритм решения

Задача решена методами класса `Matrix`. Единственное поле класса — двумерный массив `private int[,] data`, он инициализируется при объявлении. Массив заполняется конструктором `Matrix(int rows, int columns, string name)`: значения вводятся с клавиатуры по строкам, каждое проверяется на формат и диапазон (от -1000 до 1000).

- `PartialColumnSums()` возвращает массив сумм. Для столбца с номером `j` (с нуля) суммируются первые `Rows - (j + 1)` элементов, то есть все, кроме последних `j + 1`. Последний столбец не обрабатывается, поэтому число сумм равно `Math.Min(Columns - 1, Rows - 1)`; столбцы, в которых не осталось элементов, пропускаются.
- `MaxColumnSum()` находит максимальную из этих сумм обычным циклом. Если ни одной суммы нет (например, массив из одной строки), метод выбрасывает `InvalidOperationException`; поэтому в программе размеры массива вводятся от 2.

Метод `ToString()` формирует строку-таблицу с выровненными столбцами, поэтому массив выводится прямо через `Console.WriteLine`.

### Тестирование

Введён массив 4 x 4 (с отрицательными числами, чтобы максимум был не в первом столбце). Суммы: 3 + (-5) + 5 = 3 для первого столбца без одного последнего элемента, -1 + 9 = 8 для второго без двух последних, 4 для третьего без трёх последних. Максимальная сумма равна 8, что совпадает с ручным расчётом. Проверка ввода: значение `1` для числа строк отклонено, так как нужно не менее двух, а нечисловое `abc` для первого элемента отклонено с просьбой повторить ввод.

# Задание 4

## Задача 9

### Текст задачи

**9. Бинарные файлы.**

Требование к заданию: бинарные файлы содержат числовые данные, исходный файл необходимо заполнить случайными данными, заполнение организовать отдельным методом. Задания 4–8 выполнить в виде статических методов одного класса, но отдельно от заданий 1–3.

Получить в другом файле последовательного доступа все компоненты исходного файла, кроме тех, которые кратны k.

### Алгоритм решения

Задача решена статическими методами класса `FileTasks`.

- `FillBinaryFile(path, count, min, max, random)` — отдельный метод, который заполняет исходный бинарный файл случайными целыми числами (`BinaryWriter.Write`).
- `CopyWithoutMultiples(sourcePath, targetPath, k)` читает исходный файл числами (`BinaryReader.ReadInt32`) до конца потока (`Position < Length`) и записывает в новый файл только те числа, у которых `value % k != 0`.
- `ReadBinaryFile(path)` читает файл целиком для вывода на экран.

Количество чисел и значение k вводятся с клавиатуры и проверяются (k от 1 до 100, так как деление на 0 недопустимо).

### Тестирование

Введено 15 чисел и k = 3; значение `0` для k отклонено. В исходном файле числа: 28 71 94 10 56 -83 -56 -11 72 12 37 -91 -71 51 100. Кратные 3 (72, 12, 51) в новый файл не попали, остальные скопированы в прежнем порядке: 28 71 94 10 56 -83 -56 -11 37 -91 -71 100.

# Задание 6

## Задача 9

### Текст задачи

**9. Текстовые файлы.**

Требование к заданию: в текстовом файле хранятся целые числа по одному в строке, исходный файл необходимо заполнить случайными данными, заполнение организовать отдельным методом.

В файле найти сумму максимального и минимального элементов.

### Алгоритм решения

- `FillNumbersPerLine(path, count, min, max, random)` — отдельный метод заполнения: записывает в текстовый файл случайные целые числа от -100 до 100, по одному в строке (`StreamWriter.WriteLine`).
- `SumOfMaxAndMin(path)` читает файл построчно (`StreamReader.ReadLine`), преобразует строки в числа (`int.Parse`) и за один проход находит минимум и максимум; возвращается их сумма. Для пустого файла выбрасывается исключение, но программа всегда записывает не менее одного числа.

Количество чисел вводится с клавиатуры и проверяется (от 1 до 30).

### Тестирование

В файл записано 10 чисел. Максимальный элемент равен 88, минимальный равен -84, их сумма 4 — совпадает с ручным расчётом по содержимому файла, показанному на скриншоте.

# Задание 7

## Задача 9

### Текст задачи

**9. Решить задачу с использованием структуры «текстовый файл».**

Требование к заданию: в текстовом файле хранятся целые числа по нескольку в строке, исходный файл необходимо заполнить случайными данными, заполнение организовать отдельным методом.

Вычислить сумму чётных элементов.

### Алгоритм решения

- `FillNumbersSeveralPerLine(path, lines, maxPerLine, min, max, random)` — отдельный метод заполнения: в каждую строку записывается случайное количество чисел (от 1 до `maxPerLine`) от -50 до 50, разделённых пробелами.
- `SumOfEven(path)` читает файл построчно, каждую строку делит на числа методом `Split(' ', StringSplitOptions.RemoveEmptyEntries)`, преобразует их в `int` и суммирует те, для которых `value % 2 == 0` (отрицательные чётные числа тоже учитываются).

Количество строк (до 10) и максимальное количество чисел в строке (до 10) вводятся с клавиатуры и проверяются.

### Тестирование

В файле 5 строк с числами. Чётные элементы: 30, 10, 50, 32, 8, -24, 38, 6, 4, 6, 34. Их сумма равна 194, программа вывела то же значение.

# Задание 8

## Задача 9

### Текст задачи

**9. Текстовый файл.**

Требование к заданию: в текстовом файле хранится текст.

Создать новый текстовый файл, каждая строка которого содержит первый символ соответствующей строки исходного файла.

### Алгоритм решения

- `FillTextFile(path, lines, random)` — отдельный метод заполнения: записывает в исходный файл случайно выбранные строки из набора заготовок (в набор входит и пустая строка).
- `WriteFirstChars(sourcePath, targetPath)` читает исходный файл построчно и записывает в новый файл первый символ каждой строки (`line[0]`). Для пустой строки в новый файл записывается пустая строка, чтобы строки файлов соответствовали друг другу.

Количество строк вводится с клавиатуры и проверяется (от 1 до 15).

### Тестирование

В исходный файл записано 7 строк. В новом файле в каждой строке стоит первый символ соответствующей строки исходного файла.

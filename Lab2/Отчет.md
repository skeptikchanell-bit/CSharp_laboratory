# Задание 1

## Задача 1

### Текст задачи

**1. Точка координат.**

Создайте сущность Точка, расположенную на двумерной плоскости, которая описывается:

- Координата Х: число
- Координата Y: число
- Может возвращать текстовое представление вида “{X;Y}”

Необходимо создать три точки с разными координатами и вывести на экран их текстовое представление.

### Алгоритм решения

Для хранения точки создан класс `Point`.

- Координаты хранятся в закрытых полях `x` и `y`, которые при объявлении инициализируются значением 0.
- Доступ к координатам даёт пара свойств `X` и `Y` с явными блоками `get` и `set` .
- Конструктор `Point(int x, int y)` задаёт обе координаты.
- Переопределённый метод `ToString()` возвращает строку вида `{X;Y}`.

В методе `Main` (через меню) пользователь вводит координаты трёх точек. Каждое число проверяется на формат и на диапазон от -1000 до 1000, точка, которая уже была введена, отклоняется (координаты должны быть разными). Затем программа создаёт три объекта `Point` и выводит их текстовое представление.

### Тестирование

Программа запрашивает координаты трёх точек. На скриншоте показана проверка ввода: нечисловое значение (`abc`), число вне диапазона (`5000`) и повторяющаяся точка (`1;2` введена второй раз) отклоняются, после чего ввод запрашивается заново. Итог: созданы три точки с разными координатами `{1;2}`, `{-3;4}` и `{5;-6}`.

# Задание 2

## Задача 1

### Текст задачи

**1. Прямая.**

Создайте сущность Линия, расположенную на двумерной плоскости, которая описывается:

- Координата начала: Точка
- Координата конца: Точка
- Может возвращать текстовое представление вида “Линия от {X1;Y1} до {X2;Y2}”

Для указания координат нужно использовать сущность Точка, разработанную в задании 1.1. Создайте линии со следующими характеристиками:

1. Линия 1 с началом в т. {1;3} и концом в т.{23;8}.
2. Линия 2, горизонтальная, на высоте 10, от точки 5 до точки 25.
3. Линия 3, которая начинается всегда там же, где начинается линия 1, и заканчивается всегда там же, где заканчивается линия 2. Таким образом, если положение первой или второй линии меняется, то меняется и третья линия.
4. После создания всех трех объектов измените координаты первой и второй линий, причем сделайте это таким образом, чтобы положение третьей линии соответствовало требованиям пункта 3.
5. Измените координаты первой линии так, чтобы при этом не изменились, координаты третьей линии.

### Алгоритм решения

Создан класс `Line`: два закрытых поля `start` и `end` типа `Point` (инициализируются точкой `{0;0}`), свойства `Start` и `End`, конструктор `Line(Point start, Point end)` и метод `ToString()`, который возвращает «Линия от {X1;Y1} до {X2;Y2}».

`Point` — ссылочный тип, поэтому линия хранит не копии точек, а ссылки на объекты. Это используется для решения задачи:

1. Линия 1: `new Line(new Point(1, 3), new Point(23, 8))`.
2. Линия 2 (горизонтальная, высота 10): `new Line(new Point(5, 10), new Point(25, 10))`.
3. Линия 3: `new Line(line1.Start, line2.End)`. Её начало и конец — это те же самые объекты, что начало линии 1 и конец линии 2, поэтому она «следует» за ними.
4. Меняются свойства `X` и `Y` самих точек (например, `line1.Start.X = 4`). Объекты остаются прежними, поэтому линия 3 тоже меняется.
5. Линии 1 назначаются новые объекты (`line1.Start = new Point(...)`). Линия 3 по-прежнему ссылается на прежние объекты, поэтому её координаты не меняются.

### Тестирование

На скриншоте показаны все пункты задания. После пунктов 1-3 линия 3 равна `{1;3}` — `{25;10}`, то есть начинается в начале линии 1 и заканчивается в конце линии 2. После пункта 4 (изменены координаты точек) линия 3 изменилась вместе с ними: `{4;6}` — `{40;10}`. После пункта 5 (линии 1 назначены новые точки) линия 3 осталась прежней.

# Задание 3

## Задача 1

### Текст задачи

**1. Студент.**

Создайте сущность Студент, которая описывается:

- Имя: строка
- Оценки: массив целых чисел.
- Может возвращать текстовое представление вида “Имя: [оценка1, оценка2,…,оценкаN]”

Необходимо выполнить следующие задачи:

1. Создать студента Васю с оценками: 3,4,5.
2. Создать студента Петю и скопировать оценки Васи, присвоив содержимое поля с оценками Васи полю с оценками Пети.
3. Заменить первую оценку Пети на число 5. Вывести на экран строковое представление Васи и Пети. Объяснить результат
4. Создать студента Андрея и скопировать ему оценки Васи так, чтобы изменение оценок Васи не влияло на Андрея.

### Алгоритм решения

Создан класс `Student`: закрытые поля `name` (инициализируется пустой строкой) и `grades` (инициализируется пустым массивом), свойства `Name` и `Grades`, конструктор и метод `ToString()`, который возвращает строку вида `Вася: [3, 4, 5]`.

1. Вася создаётся с оценками 3, 4, 5.
2. Петя создаётся без оценок, после чего выполняется присваивание `petya.Grades = vasya.Grades`. Копируется ссылка на массив, а не его содержимое.
3. Первая оценка Пети заменяется: `petya.Grades[0] = 5`. Выводятся строки Васи и Пети.
4. Для Андрея создаётся отдельный массив той же длины, в него копируются элементы (`Array.Copy`), и этот массив передаётся студенту. После этого изменение оценок Васи не влияет на Андрея.

### Тестирование

После замены первой оценки Пети на 5 изменились оценки обоих студентов: `Вася: [5, 4, 5]` и `Петя: [5, 4, 5]`.

**Объяснение результата.** Массив в C# — ссылочный тип. Присваивание `petya.Grades = vasya.Grades` копирует не оценки, а ссылку на массив, поэтому поля обоих студентов указывают на один и тот же массив в памяти. Изменение элемента через Петю меняет этот общий массив, и оно видно у Васи.

Для Андрея создана настоящая копия массива. Когда первая оценка Васи заменена на 2, у Васи получилось `[2, 4, 5]`, а у Андрея остались `[5, 4, 5]`.

## Задача 7

### Текст задачи

**7. Создаем Студента.**

Измените сущность Студент из задачи 3.1. Новые требования включают:

- Студента можно создать указав только имя
- Студента можно создать указав имя и набор оценок
- Оба способа должны быть реализованы единственным конструктором

Создайте и выведите на экран следующие объекты:

1. Студент Вася с оценками: 3,4,5.
2. Студент Максим без оценок

### Алгоритм решения

В классе `Student` оба способа создания реализованы одним конструктором `Student(string name, params int[] grades)`. Ключевое слово `params` позволяет передать оценки отдельными числами: `new Student("Вася", 3, 4, 5)`. Если оценки не указаны, параметр `grades` получает пустой массив: `new Student("Максим")`. Для пустого массива `ToString()` выводит `Максим: []`.

### Тестирование

Программа создала студента Васю с оценками и студента Максима без оценок: `Вася: [3, 4, 5]` и `Максим: []`.

# Задание 5

## Задача 6

### Текст задачи

**6. Студент отличник.**

Измените сущность Студент из задачи 4.7. Новые требования включают:

- Студент может возвращать значение своей средней оценки (вещественное число). Если оценок нет, то среднее – 0.
- Студент может возвращать информацию о том, является ли он отличником или нет. Студент является отличником если у него есть хотя бы одна оценка и все оценки только отличные.

Необходимо выполнить следующие задачи:

1. Создайте студента Васю с оценками 3,4,5,4
2. Создайте студента Петю с оценками 5,5,5,5
3. Выведите для обоих студентов информацию о среднем балле и являются ли они отличниками

### Алгоритм решения

В класс `Student` добавлены два свойства только для чтения.

- `Average` (тип `double`) возвращает средний балл. Если оценок нет, возвращается 0. Иначе в цикле `foreach` суммируются оценки, и сумма делится на их количество; сумма приводится к `double`, чтобы деление было вещественным.
- `IsExcellent` (тип `bool`) возвращает признак отличника. Если оценок нет, возвращается `false`. Иначе в цикле проверяется, что каждая оценка равна 5 (закрытая константа `ExcellentGrade`); при первой же другой оценке сразу возвращается `false`.

### Тестирование

Для Васи (3, 4, 5, 4) средний балл равен 4,00, и он не отличник. Для Пети (5, 5, 5, 5) средний балл равен 5,00, и он отличник.

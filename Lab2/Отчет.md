### Текст задачи

**9. Заполнение двумерных массивов.**

Требование к заданию: реализовать в виде конструкторов (кроме них, могут быть и другие конструкторы). Класс содержит единственное поле – двумерный массив.

Первый массив, размерностью n х m , заполняется данными, вводимыми с клавиатуры, так что заполнение ведется по строкам от первых элементов строки к последним.

Второй массив, размерностью n х n, заполняется случайными числами так, что четные числа заносятся в элементы массива, которые на шахматной доске были бы черными, а нечетные числа заносятся в элементы, которые на шахматной доске были бы белыми.

Третий массив, размерностью n х n, заполняется для произвольного n так же, как для n=5:

```
11  0  0  0  0
 7 12  0  0  0
 4  8 13  0  0
 2  5  9 14  0
 1  3  6 10 15
```

### Алгоритм решения

Все три массива создаются конструкторами класса `Matrix`. Единственное поле класса — двумерный массив `private int[,] data`, он инициализируется при объявлении.

1. **Первый массив** — конструктор `Matrix(int rows, int columns, string name)`. Два вложенных цикла идут по строкам, внутри строки — от первого элемента к последнему; каждое значение запрашивается у пользователя через `ConsoleInput.ReadInt`, который проверяет формат и диапазон (от -1000 до 1000) и повторяет запрос при ошибке.
2. **Второй массив** — конструктор `Matrix(int size, Random random)`. Клетка `[i, j]` считается чёрной, если сумма индексов `i + j` чётная (клетка `[1,1]` в нумерации с единицы чёрная). В чёрные клетки записывается чётное число `2 * random.Next(0, 51)` (от 0 до 100), в белые — нечётное `2 * random.Next(0, 50) + 1` (от 1 до 99).
3. **Третий массив** — конструктор `Matrix(int size)`. Числа 1, 2, 3, ... записываются по диагоналям, параллельным главной, начиная с левого нижнего угла: внешний цикл идёт по смещению диагонали от `size - 1` до 0, внутренний — вдоль диагонали сверху вниз. Выше главной диагонали остаются нули. При `size = 5` получается массив из условия.

Дополнительно есть конструктор `Matrix(int[,] data)` для готового массива (его используют операторы и транспонирование). Метод `ToString()` формирует таблицу с выровненными столбцами.

### Текст задачи

**9. Работа с двумерными массивами.**

Задан двумерный массив. Найдите сумму элементов первого столбца без одного последнего элемента, сумму элементов второго столбца без двух последних, сумму третьего столбца без трех последних и т.д. Последний столбец не обрабатывается. Среди найденных сумм найдите максимальную.

### Алгоритм решения

Задача решена методами класса `Matrix`.

- `PartialColumnSums()` возвращает массив сумм. Для столбца с номером `j` (с нуля) суммируются первые `Rows - (j + 1)` элементов, то есть все, кроме последних `j + 1`. Последний столбец не обрабатывается, поэтому число сумм равно `Math.Min(Columns - 1, Rows - 1)`; столбцы, в которых не осталось элементов, пропускаются.
- `MaxColumnSum()` находит максимальную из этих сумм обычным циклом. Если ни одной суммы нет (например, массив из одной строки), метод выбрасывает `InvalidOperationException`; поэтому в программе размеры массива вводятся от 2.

Размеры массива и его элементы вводятся с клавиатуры с проверкой.

### Текст задачи

**9. Работа с двумерными массивами как с матрицами.**

Требование к заданию: перегрузить необходимые операторы и посчитать значение матричного выражения (решение без перегрузки не принимается). Перегрузить метод ToString() — сформировать строку из двумерного массива для отображения его на экране в виде таблицы. Приложить в отчет скрин-шот проверки на онлайн-калькуляторе, чтобы показать, что выражение посчитано верно.

Выражение:

```
(А+4*В)-Ст
```

(Ст — транспонированная матрица C.)

### Алгоритм решения

В класс `Matrix` добавлены перегруженные операторы:

- `operator +(Matrix, Matrix)` и `operator -(Matrix, Matrix)` — поэлементные сложение и вычитание (размеры матриц проверяются, при несовпадении выбрасывается `ArgumentException`);
- `operator *(int, Matrix)` и `operator *(Matrix, int)` — умножение матрицы на число.

Транспонирование в C# нельзя записать оператором, поэтому оно реализовано методом `Transpose()`. Выражение записывается в программе так:

```csharp
Matrix result = (a + (4 * b)) - c.Transpose();
```

Матрицы A и B имеют размер n x m, поэтому C должна иметь размер m x n: тогда Cт имеет размер n x m. Все три матрицы вводятся с клавиатуры. Метод `ToString()` формирует строку-таблицу, поэтому матрицу можно выводить прямо через `Console.WriteLine`.

**9. Бинарные файлы.**

Требование к заданию: бинарные файлы содержат числовые данные, исходный файл необходимо заполнить случайными данными, заполнение организовать отдельным методом. Задания 4–8 выполнить в виде статических методов одного класса, но отдельно от заданий 1–3.

Получить в другом файле последовательного доступа все компоненты исходного файла, кроме тех, которые кратны k.

### Алгоритм решения

Задача решена статическими методами класса `FileTasks`.

- `FillBinaryFile(path, count, min, max, random)` — отдельный метод, который заполняет исходный бинарный файл случайными целыми числами (`BinaryWriter.Write`).
- `CopyWithoutMultiples(sourcePath, targetPath, k)` читает исходный файл числами (`BinaryReader.ReadInt32`) до конца потока (`Position < Length`) и записывает в новый файл только те числа, у которых `value % k != 0`.
- `ReadBinaryFile(path)` читает файл целиком для вывода на экран.

Количество чисел и значение k вводятся с клавиатуры и проверяются (k от 1 до 100, так как деление на 0 недопустимо).

**9. Бинарные файлы и структуры.**

Требование к заданию: бинарные файлы содержат величины типа struct, заполнение исходного файла необходимо организовать отдельным методом, обязательно использовать xml сериализацию, решение без сериализации не принимается.

Файл содержит сведения об игрушках: название игрушки, ее стоимость в рублях и возрастные границы (например, игрушка может предназначаться для детей от двух до пяти лет). Получить сведения о том, можно ли подобрать игрушку, любую, кроме мяча, подходящую ребенку трех лет.

### Алгоритм решения

Сведения об игрушке хранятся в структуре `Toy` (поля: название, стоимость, минимальный и максимальный возраст; свойства с явными `get` и `set`, конструктор и `ToString()`).

- `FillToyFile(path, count, random)` — отдельный метод заполнения: создаёт массив `Toy[]` из случайных игрушек и записывает его в файл через `XmlSerializer.Serialize`.
- `ReadToyFile(path)` читает игрушки обратно через `XmlSerializer.Deserialize`.
- `HasToyExceptBall(path, age)` читает файл и в цикле ищет игрушку, название которой не «Мяч» (сравнение без учёта регистра) и у которой `MinAge <= age <= MaxAge`. Если такая найдена, возвращается `true`, иначе `false`.

Возраст ребёнка задан константой 3 в соответствии с условием, количество игрушек вводится с клавиатуры (от 1 до 20).

Создать новый текстовый файл, каждая строка которого содержит первый символ соответствующей строки исходного файла.

### Алгоритм решения

- `FillTextFile(path, lines, random)` — отдельный метод заполнения: записывает в исходный файл случайно выбранные строки из набора заготовок (в набор входит и пустая строка).
- `WriteFirstChars(sourcePath, targetPath)` читает исходный файл построчно и записывает в новый файл первый символ каждой строки (`line[0]`). Для пустой строки в новый файл записывается пустая строка, чтобы строки файлов соответствовали друг другу.

Количество строк вводится с клавиатуры и проверяется (от 1 до 15).

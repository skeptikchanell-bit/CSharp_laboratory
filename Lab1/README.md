Метод `FindAll`. Выполняются два прохода по массиву. Первый подсчитывает количество вхождений числа x, после чего создаётся массив нужной длины. Второй проход записывает в него индексы совпадающих элементов. Если вхождений нет, возвращается пустой массив.

Проверка на примере из условия: `arr=[1,2,3,8,2,2,9] x=2` → `[1,4,5]`. Результат работы программы совпадает с ожидаемым.
